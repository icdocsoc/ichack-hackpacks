# Frontend Development

Frontend refers to the part of the app that users interact with, like websites or mobile UI. There's many ways of doing this, including some detailed in [the Android hackpack](TODO) for mobile apps.

Web development is one of the most common ways to make frontend thanks to its simplicity (you can write it once, and it'll run anywhere that has a browser). Two of the most common frameworks are React and Vue.js. React is closer to standard Java/TypeScript, but Vue.js is often lauded for a more pleasant developer experience due to automatic reactivity (detailed in the Vue.js hackpack).
