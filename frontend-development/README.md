# Frontend Development

Frontend refers to the part of the app that users interact with, like websites or mobile UI. There's many ways of doing this, including some detailed in [the Android hackpack](TODO) for mobile apps.

Web development is one of the most common ways to make frontend thanks to its simplicity (you can write it once, and it'll run anywhere that has a browser). Two of the most common frameworks are React and Vue.js. React is closer to standard Java/TypeScript, but Vue.js is often lauded for a more pleasant developer experience due to automatic reactivity (detailed in the Vue.js hackpack).

## Vue.js
Vue.js is a TypeScript/JavaScript framework for building user interfaces and single-page applications. It builds on top of standard web technology — HTML, CSS and JavaScript — to allow incremental adoption, or the ability to add it seamlessly on top of vanilla websites without changing existing code (much). It's best known for its component-based architecture, allowing you to use the existing component style of HTML with what feel like custom elements.

Vue.js is designed to complement existing HTML, which makes it very easy to add to existing web projects. It's also useful to build from scratch, and the Hackpack covers this use-case. Many complementary frameworks for Vue.js exist, most notably [Nuxt](https://nuxt.com/) which adds a backend to complete the full-stack.

## React
React is another similar framework that leans more into the imperative style. While it also complements HTML with additional tags and features (known as JSX) it leans more heavily into TypeScript or JavaScript code to achieve things.

React also has good support for non-web UIs, known as [React Native](https://reactnative.dev/). It's possible to build full mobile apps with this (in conjuntion with [Expo](https://github.com/expo/expo)) leaning into the write-once-run-everywhere philosophy.
